# Satya

Zentrales privates Repository für **Crypto-, Celo- und MiniPay-bezogene Projekte**.

> Dieses Repository ist privat, weil die Archive öffentliche Wallet-Adressen mit Finanzhistorien und personenbezogenen Kontexten verknüpfen können.

## Enthaltene Projekte

- `projects/minipay-celo-readonly/` — Nur-Lese-Monitor für Celo/MiniPay einschließlich Projektdokumentation und archivierten Berichten.
- `projects/opera-celo-minipay-context/` — privates Kontext- und Recherchearchiv zu Opera, CELO Rewards und MiniPay.
- `projects/satya/` — vollständiger datierter Satya-Quellcode-Snapshot mit Frontend/Solidity, Python-Engine/API, Tests, Demo-Material und KI-Handoffs.

Satya: zuerst [`projects/satya/context/current-chat-handoff-2026-11-01.md`](projects/satya/context/current-chat-handoff-2026-11-01.md) lesen; dann [`projects/satya/source/2026-11-01/`](projects/satya/source/2026-11-01/README.md) für den Quellcode. Der Snapshot ist privat, datiert und hat keine Git-Historie. Ausgelassene Schlüssel, generierte Daten und Build-Artefakte sind in seiner README dokumentiert.

Die ursprünglichen Repositories bleiben als separate Quellen bestehen:

- [`minipay-celo-readonly`](https://github.com/manuelpicard/minipay-celo-readonly)
- [`opera-celo-minipay-context`](https://github.com/manuelpicard/opera-celo-minipay-context)

## Sicherheitsregeln

- Keine produktiven privaten Schlüssel, Seed-Phrasen, PINs, 2FA-Codes oder Zugangsdaten committen.
- Keine Wallet-Daten in öffentliche Repositories spiegeln.
- Nur-Lese-Werkzeuge dürfen keine Signaturen oder Transaktionen auslösen.
- Historische Berichte vor einer aktuellen Auskunft zeitlich und fachlich neu prüfen.
