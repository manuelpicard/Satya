# Satya

Zentrales privates Repository für **Crypto-, Celo- und MiniPay-bezogene Projekte**.

> Dieses Repository ist privat, weil die enthaltenen Archive öffentliche Wallet-Adressen mit Finanzhistorien und personenbezogenen Kontexten verknüpfen können.

## Enthaltene Projekte

- `projects/minipay-celo-readonly/` — Nur-Lese-Monitor für Celo/MiniPay einschließlich Projektdokumentation und archivierten Berichten.
- `projects/opera-celo-minipay-context/` — privates Kontext- und Recherchearchiv zu Opera, CELO Rewards und MiniPay.

Die ursprünglichen Repositories bleiben als separate Quellen bestehen:

- [`minipay-celo-readonly`](https://github.com/manuelpicard/minipay-celo-readonly)
- [`opera-celo-minipay-context`](https://github.com/manuelpicard/opera-celo-minipay-context)

## Sicherheitsregeln

- Keine privaten Schlüssel, Seed-Phrasen, PINs, 2FA-Codes oder Zugangsdaten committen.
- Keine Wallet-Daten in öffentliche Repositories spiegeln.
- Nur-Lese-Werkzeuge dürfen keine Signaturen oder Transaktionen auslösen.
- Historische Berichte vor einer aktuellen Auskunft zeitlich und fachlich neu prüfen.
